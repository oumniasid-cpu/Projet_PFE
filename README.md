## Run the application locally

Make sure PostgreSQL is running and the backend environment variables are configured. Then double-click `run-dev.bat` from File Explorer, or run it from the project folder:

```bat
run-dev.bat
```

This opens the backend (`http://localhost:5000`) and frontend (`http://localhost:5173`) in separate terminal windows. Close those windows to stop the servers.
